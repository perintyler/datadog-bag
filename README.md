# Datadog (Barry Pack)

Query and explore Datadog logs, traces, metrics, monitors, and events.

## Tools

- `search_logs` — search application logs by query, service, and time range
- `search_traces` — search APM traces and spans across services
- `get_trace` — get the full span tree for a specific trace
- `query_metrics` — query time-series metrics with Datadog syntax
- `list_monitors` — list Datadog monitors and their statuses
- `get_monitor` — get details and history for a specific monitor
- `search_events` — search operational events (deploys, incidents, alerts)
- `status` — check Datadog connection status
